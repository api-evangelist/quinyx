Quinyx is an AI-powered workforce management (WFM) platform for frontline organizations, covering scheduling, demand forecasting, time tracking, labor law compliance, task management, and employee engagement across retail, warehousing and logistics, hospitality, facility management, and healthcare. Quinyx exposes a public developer platform with three APIs: the current REST API v3 (OAuth 2.0 client-credentials, RFC 9457 problem details, cursor pagination, regional EU/NA hosts), the earlier REST API v2, and a bearer-token User API v2, plus a legacy SOAP v1. This profile was enriched from Quinyx's own developer portal, OpenAPI descriptions, and public documentation.

**Areas:** Workforce Management · Scheduling · Human Resources · Time Tracking · Forecasting · Employee Engagement · Retail · Hospitality · Company

## How this profile is made

From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Quinyx: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
